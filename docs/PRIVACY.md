# الخصوصية

يتصل التطبيق مباشرة بخدمات عامة محددة عبر HTTPS. لا يوجد Backend وسيط؛ راجع [المصادر](SOURCES.md) لقائمة الطلبات والحقول. تخزن النتائج والمفضلة والإعدادات محليًا في Room وDataStore.

## البيانات والاتصالات

- لا يحتاج التطبيق إلى حساب أو تسجيل دخول.
- لا يجمع بيانات شخصية ولا يرسلها إلى خادم خاص.
- لا يحتوي Backend أو قاعدة بيانات سحابية.
- لا يطلب الموقع أو جهات الاتصال أو SMS أو الكاميرا أو الميكروفون أو التخزين أو الهاتف أو الحسابات.
- صلاحيتا Android الوحيدتان هما `INTERNET` و`ACCESS_NETWORK_STATE`.
- العناصر والمفضلة والإعدادات محلية على الجهاز. مسح الكاش يبقي العناصر المحفوظة في المفضلة.
- لا تُضمّن API Keys أو GitHub/Hugging Face Tokens.
- الترجمة على الجهاز اختيارية ولا يبدأ تنزيل نموذجها عند تشغيل التطبيق. عند استدعاء الترجمة، قد ينزّل ML Kit نموذج اللغة على الجهاز.
- يرسل التطبيق طلبات قراءة عامة إلى GitHub وHugging Face وGoogle Blogs وOpenAI وHugging Face Dataset Server. لا يرسل محتوى المستخدم أو المفضلة لهذه المصادر.
- لا يستخدم التطبيق Proxy لتجاوز حدود المعدل، ولا يرسل API Keys أو Tokens أو OAuth.
- استجابات RSS وJSON تُعالج لاستخراج metadata ومقتطف قصير؛ لا تُخزن المقالات كاملة ولا تُنزّل ملفات النماذج أو README.
- لا تُسجل أجسام الاستجابات في Logcat. طلبات الصور تستخدم HTTPS فقط.
- تظل نتائج Room قابلة للعرض والبحث دون اتصال. مسح Cache يحذف العناصر غير المفضلة فقط.

قد تبدأ قاعدة المحتوى فارغة إلى أن تنجح أول مزامنة؛ لا تُضاف بيانات تجريبية.
